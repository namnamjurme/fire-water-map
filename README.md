# 소방용수 관리지도 (시범)

「소방용수시설 관리체계 구축 및 운영 효율화 연구」(경일대학교 화재공학연구실) 시범 웹앱입니다.

- 소화전 성능 등급(1~4등급, 등급 외) 지도 표시, 실측/추정 구분
- 화재 지점 반경 200 m 소화전 조회와 구역 가용유량 산정
- 현장 조사 입력(외관·작동 점검, 성능시험 → 가용유량·등급 자동 계산), CSV 내보내기
- 실시간 기상(풍향·풍속·돌풍·기온·습도, Open-Meteo)과 바람 흐름 애니메이션
- 화재 확산 가시화: 화재 강도 1~10단계(1~50 MW), 풍향·풍속을 반영한 타원 확산(가시화용 단순 모델)
- 작전 명령: 화재 시나리오 요약, 반경 1·5·10 km 소화용수 확보 판정, 1차 진압·2차 대비 지점 자동 선정, 확산 방향 수동 수정, 명령문 복사
- 배경지도: OpenStreetMap, Esri 위성, 브이월드(인증키), 오프라인 도식

**현재 수록된 소화전 41개소는 시연용 예시 자료이며 실제 시설 위치·성능이 아닙니다.**
입력한 자료와 조사 기록은 각 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
